# 2단계 · 검색과 평가 (4–5주)

LLM을 제품에 넣을 때 필요한 검색과 평가를 직접 다룬다.
**이 단계부터 모든 실험은 수치로 남긴다.**

주차별 항목은 [`../CURRICULUM.md`](../CURRICULUM.md#2단계--검색과-평가-45주).

## 이번 단계에서 만드는 것

| 주차 | 초점 | 남는 것 |
| --- | --- | --- |
| 4주 | 임베딩·벡터 검색·청킹 | **직접 구현**: 프레임워크 없는 RAG (임베딩 → 검색 → 재순위 → 생성) |
| 5주 | 평가 | 골든셋, LLM-as-judge, recall@k·MRR, **산출물**: 설정별 비교표 |

RAG는 LangChain·LlamaIndex 없이 만든다. 데이터는 Facton 기사를 쓴다.

## 기록 규칙

실험 하나 = 설정 + 측정값 한 줄. 최소 항목:

| 항목 | 예 |
| --- | --- |
| 품질 | recall@k, MRR, judge 점수 |
| 지연 | p50 / p95 (ms) |
| 비용 | 입출력 토큰, 달러 (로컬은 0, 대신 시간) |
| 조건 | 모델, 데이터셋, 하드웨어, 날짜 |

원본은 `results/`에, 요약 표는 이 README에 올린다. 재현 스크립트를 반드시 같이 낸다.
