# 2단계 · LLM 응용 (11–16주)

LLM을 제품에 넣을 때 필요한 검색, 평가, 튜닝, 서빙을 직접 다룬다.
**이 단계부터 모든 실험은 수치로 남긴다.**

주차별 항목은 [`../CURRICULUM.md`](../CURRICULUM.md#2단계--llm-응용-11-16주).

## 이번 단계에서 만드는 것

| 주차 | 초점 | 남는 것 |
| --- | --- | --- |
| 11주 | 토크나이저 | **직접 구현**: BPE 토크나이저, 토큰 수 ↔ 비용·지연 측정 |
| 12주 | 임베딩·벡터 검색·청킹 | **직접 구현**: 프레임워크 없는 RAG (임베딩 → 검색 → 재순위 → 생성) |
| 13주 | 평가 | 골든셋, LLM-as-judge, recall@k·MRR, 설정별 비교표 |
| 14주 | 파인튜닝 | transformers + PEFT LoRA로 소형 오픈 모델 튜닝 |
| 15주 | 서빙 | vLLM, 배칭·KV 캐시. 튜닝 모델 vs API 모델 비교 |
| 16주 | 정리 | **산출물**: 벤치마크 리포트 |

12주 RAG는 LangChain·LlamaIndex 없이 만든다. 프레임워크 비교는 3단계에서 한다.

## 기록 규칙

실험 하나 = 설정 + 측정값 한 줄. 최소 항목:

| 항목 | 예 |
| --- | --- |
| 품질 | recall@k, MRR, judge 점수 |
| 지연 | p50 / p95 (ms) |
| 비용 | 입출력 토큰, 달러 |
| 조건 | 모델, 데이터셋, 하드웨어, 날짜 |

원본은 `results/`에, 요약 표는 이 README와 리포트에 올린다. 리포트에는 재현 스크립트를 반드시 같이 낸다.
