# 캡스톤 · 업무 자동화 멀티에이전트

모든 단계 산출물을 하나로 묶는다. 대상은 본업에서 쓰는 Jira·Confluence·GitHub 흐름이라
실무 경험과 바로 이어진다.

## 구성

에이전트 3개 + MCP 서버 3개. **에이전트마다 프레임워크를 일부러 다르게 쓴다.**
그래야 A2A가 진짜 이기종 연동이 되고, 3단계 비교 글 거리도 나온다.

각 에이전트가 어떤 프레임워크를 쓸지는 21주에 프레임워크를 직접 써 본 뒤 정한다.

## 마일스톤

| 버전 | 시점 | 내용 |
| --- | --- | --- |
| v1 | 24주 (3단계 끝) | 에이전트 3개 + MCP 서버 3개, A2A 협업, 평가 수치(성공률·스텝 수·비용) |
| v2 | 30주 (4단계 끝) | 컨테이너·배포·관측·CI 평가 연결, 외부 사용자 실트래픽 |

## 선행 조건

- 3단계 17–23주 구현물 (에이전트 루프, MCP 서버, A2A, GraphRAG)
- 2단계 RAG·평가 골든셋
- 0단계 게이트웨이 (프로바이더 추상화, 요청 로그)

아직 구현하지 않았다. 24주 항목은 [`../CURRICULUM.md`](../CURRICULUM.md#캡스톤--업무-자동화-멀티에이전트)에서 체크한다.
