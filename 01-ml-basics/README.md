# 1단계 · LLM 기초와 로컬 모델 (3주)

모델 내부는 면접에서 설명할 수 있는 수준까지만 다루고, 대신 로컬 모델을 직접 재 본다.
디렉터리 이름은 30주안 시절의 `01-ml-basics`를 그대로 둔다.

주차별 항목은 [`../CURRICULUM.md`](../CURRICULUM.md#1단계--llm-기초와-로컬-모델-3주).

## 이번 단계에서 만드는 것

| 주차 | 초점 | 남는 것 |
| --- | --- | --- |
| 3주 | 어텐션·트랜스포머 블록 (Karpathy *Let's build GPT* 한 편), 토큰·양자화·KV 캐시 | **산출물**: 로컬 모델 벤치마크 스크립트와 결과 표 |

벤치마크는 모델·양자화(4bit/8bit)·형식(GGUF/MLX)별로 tok/s, 첫 토큰 지연, 메모리 사용량을 잰다.
이 표가 3단계에서 실습 모델을 고르는 근거가 된다.

## 기록

원본은 `results/`, 요약 표는 이 README에. 측정 조건(모델, 하드웨어, 런타임 버전, 날짜)을 같이 적는다.
모델 파일은 커밋하지 않는다.

## 졸업 기준

- 트랜스포머 블록 하나를 종이에 그리고 말로 설명 가능
- 벤치마크 결과 표 공개
