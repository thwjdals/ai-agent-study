# 3단계 · Agent 코어 (6–9주)

이 직무의 본업. 각 개념을 바닥부터 만든 뒤에 프레임워크로 넘어간다.
본업의 Claude Code MCP 멀티에이전트 경험을 여기서 회수한다. 6주 하네스가 캡스톤의 몸통이다.

주차별 항목은 [`../CURRICULUM.md`](../CURRICULUM.md#3단계--agent-코어-69주).

## 이번 단계에서 만드는 것

| 주차 | 초점 | 남는 것 |
| --- | --- | --- |
| 6주 | Anthropic *Building effective agents* | **직접 구현**: 프레임워크 없는 tool calling 루프, 평가 과제 세트 20개+ |
| 7주 | 루프 엔지니어링 (반복 감지, 오류 복구, 맥락 압축, 계획 후 실행) | 개선 항목별 성공률 전후 표 |
| 8주 | MCP 스펙 (JSON-RPC, tools·resources·prompts, stdio·HTTP) | **직접 구현**: SDK 없이 MCP 서버 → 공식 SDK 재작성 후 배포 |
| 9주 | LangGraph 또는 Claude Agent SDK | 6–7주 과제 재구현 + 비교표 |

## 짝 비교 구조

직접 구현과 프레임워크 버전을 **둘 다 남긴다**. 중복이 아니라 비교 자료다.

- 6–7주 (직접 루프) ↔ 9주 (프레임워크)
- 8주 전반 (JSON-RPC 직접) ↔ 8주 후반 (공식 SDK)

비교는 코드 길이·제어 범위·디버깅 난이도에 성공률·스텝 수·비용 수치를 붙여서 표로 만든다.
7주 실험은 같은 과제 세트를 로컬 약한 모델·강한 모델·클라우드 모델로 돌려서 하네스 효과가 모델 크기별로 어떻게 다른지 본다.
