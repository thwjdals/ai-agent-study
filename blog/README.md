# 글·발표 (5단계 · 대외 검증, 상시)

내가 말하는 게 아니라 제3자가 확인해 주는 증거만 쌓는다. 별도 기간이 아니라 전 기간 병행한다.

만든 걸 글이나 발표로 풀고, **거기서 막히는 질문을 다음 학습 주제로 삼는다.**

## 예정 글 (단계마다 1편 이상)

| 단계 | 글 |
| --- | --- |
| 0단계 | TS 개발자가 본 Python 비동기 |
| 1단계 | 미니 GPT 구조 해설 |
| 2단계 | RAG 설정·파인튜닝·서빙 벤치마크 리포트 |
| 3단계 | MCP 직접 구현기 / 에이전트 프레임워크 비교 |
| 4단계 | 운영 기록 (부하 테스트, 포스트모템) |

## 쓰는 법

- 초안은 `drafts/`, 발행한 글은 `published/`에 원문을 남기고 표에 링크를 붙인다.
- 실험 글은 수치를 본문에 싣고 재현 스크립트 위치를 같이 적는다. 수치 없는 "좋아졌다"는 안 쓴다.
- 발행하면 [`../CURRICULUM.md`](../CURRICULUM.md#5단계--대외-검증-상시)의 해당 졸업 기준을 체크한다.

## 발표·OSS
