# 4단계 · 프로덕션·MLOps (25–30주)

데모가 아니라 실제로 운영되는 시스템으로 만든다. 자격증 대신 실트래픽, 부하 테스트, 장애 대응 기록이 증거다.

대상은 [`../capstone/`](../capstone/)의 v1이다. 주차별 항목은 [`../CURRICULUM.md`](../CURRICULUM.md#4단계--프로덕션mlops-25-30주).

## 이번 단계에서 만드는 것

| 주차 | 초점 | 남는 것 |
| --- | --- | --- |
| 25주 | Docker 멀티스테이지, compose | 캡스톤 컨테이너화 |
| 26주 | Kubernetes 기초 (kind) | Deployment·Service·HPA, 클라우드 배포 |
| 27주 | 관측 (OpenTelemetry, Langfuse) | 지연·토큰·비용·실패율 대시보드 |
| 28주 | CI 평가 파이프라인 | PR마다 골든셋 회귀 검사, 프롬프트·모델 버전 관리 |
| 29주 | 부하 테스트 (k6 또는 Locust) | 캐싱·병렬 tool call·모델 라우팅 전후 p95·비용 |
| 30주 | 장애 주입·대응 | 포스트모템, **아키텍처 문서** |

## 기록

29주 튜닝은 전/후를 같이 적는다. 부하 테스트 결과와 포스트모템은 `results/`에 원본, 요약은 공개 문서로.

## 졸업 기준

- 외부 사용자 트래픽 발생
- 부하 테스트 결과와 포스트모템 공개
- 글 1편 발행 → 초안은 [`../blog/`](../blog/)
